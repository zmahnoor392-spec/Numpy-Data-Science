# 3x3 Matrix Operations Project

This project provides comprehensive 3x3 matrix operations implemented in two distinct versions:
1. **Without NumPy** (`matrix_no_numpy.py`): Built using pure Python standard libraries and custom math algorithms.
2. **With NumPy** (`matrix_numpy.py`): Built using the NumPy library for high-performance matrix computations and linear algebra.

Both versions support **both GUI (Graphical User Interface)** and **CLI (Command Line Interface)** modes.

---

## Operations Supported
- Addition ($A + B$)
- Subtraction ($A - B$)
- Multiplication ($A \times B$)
- Scalar Multiplication
- Transpose ($A^T$)
- Determinant ($\det(A)$)
- Inverse ($A^{-1}$)

---

## How to Run

### 1. Without NumPy Version (`matrix_no_numpy.py`)
- **GUI Mode** (Default):
  ```bash
  python dataScience/numpy/matrix_no_numpy.py
  ```
- **CLI Mode**:
  ```bash
  python dataScience/numpy/matrix_no_numpy.py --cli
  ```

### 2. With NumPy Version (`matrix_numpy.py`)
- **GUI Mode** (Default):
  ```bash
  python dataScience/numpy/matrix_numpy.py
  ```
- **CLI Mode**:
  ```bash
  python dataScience/numpy/matrix_numpy.py --cli
  ```
